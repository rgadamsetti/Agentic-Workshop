- (direction) Source: INTENT.md. Slug: epic-1. Mode: interactive.
- (capability) CAP-1: TriageDecision schema validates that every decision has category (billing|bug|access|performance|how-to), priority (P1-P4), route (billing-team|bug-team|access-team|performance-team|how-to-team), and one-sentence rationale; rejects anything else with a clear error.
- (capability) CAP-2: load_seed.py loads seed/tickets.csv and seed/customers.csv into app.db as tables 'tickets' and 'customers' with identical columns; running it twice yields the same database (idempotent).
- (constraint) Python 3.12 or newer, managed with uv only (no pip).
- (constraint) seed/ files are read-only; load_seed.py reads them, never writes them.
- (constraint) No network calls and no API keys in this epic.
- (constraint) mcp/triage_server.py already reads app.db; table names 'tickets' and 'customers' and their column names must be preserved exactly.
- (decision) TriageDecision is a Pydantic model; validation errors raise a structured error (not a bare exception) to give callers a clear rejection message.
- (decision) load_seed.py uses SQLite's INSERT OR REPLACE (or equivalent) to achieve idempotency without dropping tables.
- (note) Non-goals from INTENT.md: agent, MCP tools, evals, and any user interface are all out of scope for Epic 1.
